ผังที่นั่ง 3D: Jan JingJing Bewitch You Fancon @ Thunder Dome

ผังที่นั่งแบบ 3 มิติของงาน JAN JINGJING BEWITCH YOU FANCON วันที่ 21–22 พฤศจิกายน 2026 ที่ Thunder Dome เมืองทองธานี ทำไว้ให้แฟนคลับใช้ดูว่าแต่ละที่นั่งอยู่ตรงไหน มองเห็นเวทีแบบไหน ศิลปินจะตัวใหญ่แค่ไหน และถ้าถ่ายด้วยมือถือรุ่นที่มี จะได้ภาพประมาณไหน
